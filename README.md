## 学习路线

1. 数学与编程基础，同时学习神经科学与手部解剖。
2. 学习脑信号处理与解码、手部运动学与控制。
3. 从仿真逐步接入实时信号，再验证实物闭环。
4. 持续积累论文、数据与实验评估记录。

## 工作原则

暴露问题并解决，验证根因，不擅自猜测与修改，不添加掩盖问题的兜底。
